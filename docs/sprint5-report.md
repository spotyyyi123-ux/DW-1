## Что сделано по задаче 4

- **Визуальный бенчмарк** (`scripts/validate_visual.py`): 21 искажение QR-изображения
  (JPEG q30–90, ресайз 15–50%, повороты 5–45°, перспектива, шум, окклюзия, blur, grayscale,
  contrast, downup). **Decode rate 19/21 = 90%**; провалы — resize_15 и perspective.
  pHash distance: 0 при сжатии/блюре, 8–26 при поворотах/перспективе.
- **RU baseline** зафиксирован для задачи Алины: GPT-Neo RU AUC 0.382, Qwen 0.5B RU 0.361;
  команда сравнения новых скоров — `scripts/compare_detectors.py`.
- Отчёт: `docs/notes/sprint5-validation.md`; сырьё — `data/runs/sprint5/visual_validation.json`.
