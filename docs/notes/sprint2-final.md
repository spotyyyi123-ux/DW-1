## Что говорить на вопросы

- **«Почему RU-часть Fast-DetectGPT не работает?»** — surrogate GPT-Neo англоязычный;
  это измеренный и задокументированный разрыв (ECE/F1/AUC), нужен RU-детектор (Sprint 3, w1).
- **«Почему Fast-DetectGPT не на письмах?»** — скоры есть только для публичного бенчмарка;
  на письмах сейчас работают обученные TF-IDF-модели, а fusion уже готов принять LLM-скоры
  (`components.ai = p_ai fast-detectgpt`).
- **«Почему BCubed F1 не измерен?»** — нужны эмбеддинги с внешнего контура и ручная
  разметка топ-50; это зафиксировано как известное ограничение, а не спрятано.
- **«Чем отличаетесь от GPTZero?»** — две оси, позлементность, кампании, калиброванные
  вероятности, контр-свидетельства, измеренная устойчивость к атакам.
- **«Откуда цифры?»** — все из сохранённых артефактов (`data/runs/sprint2/*`,
  `reports/sprint2-llm/*`), воспроизводится командами со страницы сайта.

## Ограничения (проговаривать самому)

1. RU-детекция ИИ не работает (только TF-IDF-часть).
2. Fast-DetectGPT не скорил письма — live-пайплайн на письмах без LLM-детектора.
3. BCubed F1 кампаний не измерен.
4. TF-IDF-модели ловят конкретный генератор/домен (HC3/ChatGPT TPR≈0).
