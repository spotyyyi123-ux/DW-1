# Sprint 5 · Направление калибровки русского детектора

После Sprint 4 обнаружено расхождение направлений двух схем калибровки.
Platt допускает отрицательный коэффициент, а прежняя isotonic использует возрастающую зависимость.
В новом варианте знак определяется на обучающих примерах, затем isotonic обучается на validation.
Реализация хранит знак в JSON и учитывает его при поиске скоров в карточке.

## Протокол до просмотра нового теста

- Модель Qwen2.5-0.5B выбрана по экспериментам Sprint 3/4.
  Ревизия `060db6499f32faf8b98477b0a26969ef7d8b9987`, лицензия Apache-2.0.
- Новые 600 текстов взяты из публичного CoAT (Apache-2.0), из исходной обучающей части.
  Прежние 300 русских текстов исключены по нормализованным хэшам. Между частями и со
  старыми текстами выполнен приближённый поиск near-duplicates, порог Жаккара 0.8.
  Группы исходных вариантов CoAT полностью неизвестны, поэтому остаётся риск скрытых связей.
- До токенизации по 100 текстов каждого класса на train/validation/test. Seed 20261119.
- Максимум 512 токенов. Примеры короче 32 предсказываемых токенов исключаются.
- На одинаковых новых test-строках сравниваются Platt, прежняя isotonic и isotonic со знаком train.
  Направление и порог 0.5 зафиксированы до просмотра test. ECE использует 10 интервалов.
- Изменение гиперпараметров по новому test потребует ещё одной независимой проверки.

## Воспроизведение

```bash
PYTHONPATH=src .venv/bin/python scripts/prepare_sprint5_ru.py
```

Из `data/runs/sprint5/ru/` загрузить `benchmark.jsonl` в
[ноутбук Colab](https://colab.research.google.com/github/spotyyyi123-ux/DW-1/blob/w1/sprint5-ru-calibration/scripts/external/sprint5_ru.ipynb).
Выбрать T4 GPU. На ноутбуке пользователя torch и transformers не устанавливаются.

Полученные `qwen05_new_scores.parquet` и `qwen05_new_scores.manifest.json` перенести в ту же папку.

```bash
make eval LLM=5 PY=.venv/bin/python
```

Скрипт проверяет отсутствие пересечения со старым бенчмарком и соответствие меток,
групп и сплитов исходному новому JSONL. Все тестовые прогнозы сохраняются.
Загрузчик JSON-калибратора должен воспроизвести каждый прогноз.

Публичные письма LLMGen/Nazario из предыдущей задачи англоязычные.
RU-калибровка измеряется на CoAT. Проверка новой шкалы на русских письмах остаётся
отдельным экспериментом при появлении публичной размеченной русской почты.

## Результаты

[Сгенерированная таблица](../../reports/sprint5-ru/report.md) и
[полные метрики](../../reports/sprint5-ru/metrics.json) получены из настоящего Colab-прогона.
Из 600 входных текстов 467 прошли минимум токенов. Новый test содержит 158 текстов.
Учёт направления улучшил AUC и F1 относительно прежней возрастающей isotonic,
но качество остаётся умеренным. Platt дал лучшую ECE и F1 среди рассмотренных вариантов.
Результат 0.72 на знакомом старом test был предварительным. Новый test дал AUC 0.597
для isotonic с направлением train.

95% парный bootstrap-интервал разности AUC новой и прежней isotonic положителен
на этой выборке. Интервал и все прогнозы сохранены. Коэффициенты и порог по test
не подбирались. Используется тот же корпус CoAT, поэтому независимый новый домен
этим экспериментом не проверен.

Проверены загрузка JSON-калибратора для каждого тестового прогноза и
сквозной анализ двух MIME-писем с публичным телом CoAT. Это техническая проверка
карточки, качество на русской электронной почте здесь не измеряется.

Для подключения полученных публичных скоров в проекте задать
`DW1_LLM_SCORES=data/runs/sprint5/ru/qwen05_new_scores.parquet` и
`DW1_LLM_CALIBRATION=data/runs/sprint5/ru/calibration.json`.
Архив с parquet и калибратором передаётся команде вне Git.
