## Задача 1 — RU-детектор v3

**Проблема:** GPT-Neo RU AUC 0.382, Qwen2.5-0.5B RU AUC 0.361 — уровень случайного.

1. Взять модель крупнее (Qwen2.5-1.5B) или RU-специализированную (mGPT) на внешнем контуре.
2. Прогнать Fast-DetectGPT на CoAT, откалибровать RU (isotonic), сравнить ECE/F1/AUC.
3. При улучшении — обновить скоры по письмам (перенос шкалы).

**Критерий:** таблица «до/после» по RU; либо документированный вывод о пределе метода.

## Задача 2 — Images v2

**Проблема:** сейчас images — только измерения (pHash/FFT/EXIF), без детектора «ИИ-картинка».

1. Выбрать публичный набор AI-vs-real изображений (CIFAKE/NTIRE, лицензия — записать в datasheet).
2. Признаки: эмбеддинги (CLIP/ResNet) + FFT/pHash; классификатор с калибровкой.
3. Устойчивость: JPEG-сжатие, ресайз, кроп; метрика AUC/F1 до/после атак.

**Критерий:** детектор изображений с AUC/F1 и таблицей устойчивости; обе оси остаются unknown
для измерительных признаков (не выдавать измерения за детектор).

## Задача 3 — QR v2

**Проблема:** текущий декодер: single/multi QR, без препроцессинга; часть искажений не читается.

1. Препроцессинг: upscale (×2/×4), adaptive threshold, поворот, инверсия.
2. Тест на искажениях: JPEG q=90/70/50, ресайз 50/25%, поворот 5/15°, grayscale, blur.
3. QR-URL → в общий анализ ссылок; чёткие статусы (нет декодера/ошибка/не декодирован).

**Критерий:** decode rate до/после на синтетическом наборе искажений; тесты.

## Задача 4 — Валидация RU и визуальных сигналов (тимлид)

1. **RU-валидация:** сравнение детекторов (GPT-Neo/Qwen/новая модель) на общих текстах —
   `scripts/compare_detectors.py`; таблица до/после калибровки.
2. **Визуальная валидация:** бенчмарк устойчивости QR/изображений на искажениях —
   `scripts/validate_visual.py` (decode rate, pHash distance, статусы).
3. Финальный отчёт/сайт Sprint 5, шпаргалка защиты; тег `m5`.

**Критерий:** сводная таблица RU и визуальных метрик; отчёт/сайт обновлены; тег `m5`.
