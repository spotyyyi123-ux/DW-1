## Ключевые цифры

- **Калибровка фузии:** ECE provenance 0.007→0.006, intent 0.361→0.007.
- **Рабочая точка:** intent TPR 0.993 при FPR 1.5%; при FPR≤1% — TPR 0.96 (порог 0.85).
- **Легит-почта:** 0% FP на 100 письмах Enron (было 81% стиль / 3% интент).
- **Fast-DetectGPT EN:** ECE 0.243→0.024, F1 0.89→0.99, AUC 0.982→0.989;
  **RU:** AUC 0.406→0.434 — ограничение.
- **Атаки:** intent TPR 0.92–0.94 (деградация ≤1.2%), provenance ≤1.7%.
- **Кампании:** 20 304 письма → 427 кластеров; скелет шаблона извлекается.

## Детали задачи 4 (тимлид)

1. **Бенчмарк писем** (`scripts/prepare_bench.py`): 600 писем — LLMGen AI-фишинг (200),
   seven-phishing spam/ham (250), enron spam/ham (150); метки в `labels.csv`; бенчмарк
   исключён из обучения.
2. **Калибровка fusion** (`scripts/calibrate_fusion.py`): isotonic на train-сплите (70/30),
   результат на test (180 писем): ECE provenance 0.318→0.013, intent 0.367→0.060.
3. **Модель происхождения** (`scripts/train_prov_model.py`): TF-IDF→SVD→HistGB на письмах;
   holdout accuracy 0.9996 (in-domain); кросс-генераторный тест HC3/ChatGPT: TPR 0.0 —
   модель ловит конкретный генератор, а не «ИИ вообще».
4. **Модель намерения** (`scripts/train_intent_model.py`): 53 211 писем, holdout F1 0.970
   / AUC 0.996; на бенчмарке TPR 0.993 @ FPR 1.5%.
5. **Faithfulness** (`scripts/faithfulness.py`): comprehensiveness/sufficiency по элементам;
   comprehensiveness 0.1–0.35 на демо-письмах.
6. **Легит-почта** (`scripts/legit_fp.py`): FP-стиль 81% → 0%, FP-интент 3% → 0%.
7. **Operating points** (`scripts/operating_points.py`): порог 0.85 → TPR 0.96 при FPR 0.5%.
8. **Fusion-интеграция Fast-DetectGPT**: `components.ai = p_ai` (приоритет над TF-IDF,
   защита от двойной калибровки); порог отказа 0.6 (`rejected_axes`).

## Что говорить на вопросы

- **«Почему RU-часть Fast-DetectGPT не работает?»** — surrogate GPT-Neo англоязычный;
  разрыв измерен (ECE/F1/AUC), нужен RU-детектор (Sprint 3, Алина).
- **«Почему Fast-DetectGPT не на письмах?»** — скоры есть только для публичного бенчмарка;
  на письмах работают TF-IDF-модели, fusion готов принять LLM-скоры (`components.ai = p_ai`).
- **«Почему BCubed F1 не измерен?»** — нужны эмбеддинги с внешнего контура и ручная
  разметка топ-50; зафиксировано как известное ограничение.
- **«Чем отличаетесь от GPTZero?»** — две оси, позлементность, кампании, калиброванные
  вероятности, контр-свидетельства, измеренная устойчивость к атакам.
- **«Откуда цифры?»** — из сохранённых артефактов (`data/runs/sprint2/*`,
  `reports/sprint2-llm/*`), воспроизводится командами.

## Ограничения

1. RU-детекция ИИ не работает (только TF-IDF-часть).
2. Fast-DetectGPT не скорил письма — live-пайплайн на письмах без LLM-детектора.
3. BCubed F1 кампаний не измерен.
4. TF-IDF-модели ловят конкретный генератор/домен (HC3/ChatGPT TPR≈0).
