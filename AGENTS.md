> Этот файл читается DSH-агентами автоматически. Правь его только через MR с ревью наставника.
> Человеческие подробности: `docs/SPEC.md` (ТЗ) и `docs/TEAM.md` (роли и задачи).

## Проект одной строкой

Детекция писем и кампаний с признаками генеративного ИИ + **explainable spam-enrichment**:
модуль, который для аналитика SOC объясняет, какие элементы письма могли быть сгенерированы или
модифицированы ИИ и насколько система уверена. Заказчик: Doctor Web. Кейс: DW-1.

## Нерушимые принципы (нарушение = отклонение MR)

1. **Две оси, не одна.** `ai_provenance` (кем написано: human / ai / ai_polished / template / unknown)
   и `intent` (зачем: фишинг / спам / легитимно) — отдельные предсказания, отдельная калибровка.
   Схлопывать в один score запрещено.
2. **Позлементность.** Тема, тело, CTA, HTML, изображения, QR, ссылки, заголовки, шаблон —
   каждый элемент получает свою атрибуцию происхождения. Бинарный вердикт «письмо написано ИИ»
   — не является результатом проекта.
3. **Объяснение без измерения достоверности не существует.** Каждое объяснение должно иметь
   faithfulness-оценку (comprehensiveness / sufficiency, см. SPEC §9).
4. **Все цифры — из `make eval`.** Никаких чисел, вбитых руками. Предсказания сохраняются
   (`data/runs/<run_id>/predictions.parquet`), отчёты генерируются из них.
5. **Внутренние данные заказчика не покидают контур.** Облачные API (GPTZero, OpenAI и т.п.) —
   только на публичных датасетах. Нарушение — стоп проекта.
6. **Никаких выдуманных результатов.** Если не воспроизводится — фиксируем как «не воспроизведено»
   в отчёте, а не подгоняем.

## Рабочий протокол агента

1. Агент работает только в репозитории `D:\dw1` (или в воркспейсе наставника). Чужое не трогает.
2. Каждый экстрактор/модель — отдельный MR: код + тесты + артефакты запуска (логи, предсказания).
3. В MR обязательно: (а) какие метрики изменились, (б) `make eval` пройден, (в) лицензия данных.
4. Прямые коммиты в `main` запрещены; агент пушит ветку, подопечный ревьюит, наставник мёржит.
5. Долгие прогоны — фоновыми задачами; агент не «спит» в ожидании, а продолжает независимую работу.
6. Непонятная или отсутствующая лицензия у датасета — блокер: стоп и эскалация, а не «возьмём так».
